# KooAI 选品报告 V2 规范

## 目标

报告应以表格帮助卖家比较市场表现、1688 成本线索、利润空间和进入理由，而不是用大量卡片或内部警告占据页面。

## 页面结构

1. 报告摘要：主题、数据截止日、候选数、推荐数、淘汰/待核验数、已完成货源/算价数。
2. 推荐候选表：默认按推荐等级、机会分和近 28 天销量排序。
3. 淘汰/待核验表：保留被硬筛选排除或证据不足的商品，展示明确原因。
4. 导出：当前页签 CSV 与完整 XLSX。

不展示原始技术 warning、内部字段名、英文错误码或逐关卡片。

## 表格字段

页面使用固定商品识别列与横向滚动。推荐候选至少包含：

| 分组 | 字段 |
| --- | --- |
| 商品 | 图片、产品 ID、商品名称、类目、Coupang 链接 |
| 市场 | 售价（KRW）、近 28 天销量、PV、评分、评论数、配送方式/火箭颜色 |
| 货源 | 1688 搜索词、货源标题、页面报价（CNY）、MOQ、1688 链接、成本证据等级 |
| 算价 | 算价状态、正常销售税后利润、正常销售利润率、建议售价、当前售价距建议售价差额 |
| 判断 | 机会分、推荐状态、中文判断理由、下一步验证动作 |

淘汰/待核验表保留已获得的市场和货源字段，并增加淘汰状态、淘汰/待核验原因与可恢复条件。

## 简化判断

页面将原七关证据合并为四项：

| 判断项 | 主要依据 |
| --- | --- |
| 市场需求 | 销量、PV、趋势、评论 |
| 竞争与进入难度 | 评价壁垒、品牌集中、价格带、同质化 |
| 货源与利润 | 1688 SKU/规格/MOQ、统一算价结果 |
| 履约与合规风险 | 配送、品类风险、已知合规证据 |

每项状态只使用“通过 / 注意 / 淘汰 / 待核验”。商品主表只显示一条中文判断理由，优先说明最强的限制条件或入选依据。

## 1688 与统一算价

1. 1688 页面展示价统一标记为“页面报价，待确认”，不等同最终采购成本。
2. 只有 `matched_estimate` 或 `confirmed_cost` 的成本证据才允许进入统一算价。
3. 算价必须先读取当前统一配置，再调用统一算价工具；保留实际返回的利润、利润率、建议售价和可实现状态。
4. 货源未找到、规格/MOQ 未确认、人工验证中或算价服务不可用时，显示“待算价”或“算价服务不可用”，不得填写零利润或给出可盈利结论。

## 导出

完整 XLSX 至少包括：推荐候选、淘汰与待核验、1688 货源明细、算价明细。CSV 导出当前页签的对应字段。
