# 商品ID横向选品

面向韩国 Coupang 卖家的独立 AI Skill。给出商品ID或链接，输出带图片的Excel，包含类目概况、销量头部、近期潜力商品、火箭配送、1～2款1688货源及统一算价。

## 安装与依赖

将整个 `kooai-id-selection` 文件夹放入宿主的Skills目录。Codex默认目录为 `~/.codex/skills/`；其他兼容SKILL.md的宿主按其安装机制加载。本包不包含后台服务、账号或密钥。

完整任务需要：
- 已认证的KooAI MCP市场数据与算价工具，或用户环境已授权的只读市场数据适配器加统一算价服务；
- 单独安装并认证 `1688-product-find`，以及可用的 `kooai-1688-sourcing` 适配技能；
- Excel生成能力，支持嵌入图片的XLSX库（如openpyxl与Pillow），或宿主的电子表格工具。

本Skill不自动安装依赖、不配置凭据。缺少依赖时明确未完成环节。安装文档不代表在所有宿主中已完成兼容性实测。

## 使用

```text
$kooai-id-selection
商品ID：<真实ID列表>
按默认流程分析，并导出带图片与完整算价明细的Excel。
```

Skill的全部分析和Excel字段约定见 [SKILL.md](SKILL.md) 及其引用文档。

## GitHub存放

适合放入多Skill仓库的 `skills/kooai-id-selection/`。本目录使用相对引用，不依赖作者机器路径，不携带商品数据、运行产物、凭据或第三方源码。上传前核查依赖许可和仓库授权范围；本地创建不表示已经提交或推送。

本包是交给AI执行的工作流规范，不是无需AI宿主即可运行的独立应用，也不附带市场数据访问权限。
