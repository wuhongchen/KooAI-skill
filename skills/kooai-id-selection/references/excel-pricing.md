# 价格、货源与带图Excel规范

## 1. 1688匹配和成本证据

读取已安装的 kooai-1688-sourcing、1688-product-find 及所用命令reference。保留原工具完整结果，与分析映射表分开，不复制其实现到本Skill。

同一行映射：Coupang产品ID/itemId/vendorItemId、销售规格/套装数量、1688商品ID/SKU、规格数量、对应阶梯价、币种、MOQ、供应商、详情链接、两端图片、观察时间。

匹配级别：
- 高度匹配：用途和关键规格有证据对应。
- 部分匹配：明确列出材料、尺寸、数量等差异。
- 仅外观相似：图片相近，规格尚无证据。
- 未匹配/人工验证中：保留原因。

不要输出凭空生成的百分比；若提供匹配分须公开维度、权重、已验证项与证据，其含义不是同厂同款概率。

成本等级：
- display_reference：仅展示价，不能确认对应SKU/MOQ。
- matched_estimate：SKU、核心规格、销售单位及MOQ基本匹配，报价未由供应商确认。
- confirmed_cost：采购规格、数量、包装、税费/运费口径、报价与交期有确认依据。

核对“每颗/每条/每对/每套/每箱”。人民币单件成本×每个Coupang销售单位所需件数才是该销售单位采购成本；缺少数量不能强行换算。页面最低起价不代表目标SKU成本。Coupang当前选中SKU价格不与另一规格货源错配。

## 2. 统一算价

先取得当次 get_pricing_config，再按 tools/list 实际schema调用 calculate_product_pricing。记录服务、时间、公式来源/版本、汇率数值/方向/来源/日期、品类佣金证据。服务schema和返回配置为准，不在本技能硬编码税率或历史字段表。

只对 confirmed_cost 或明确标预估的 matched_estimate 调用；最低成本证据不足则记录“未算价”。非CNY货源先使用有来源、有日期的汇率转换，不能把币种混入人民币字段。

输入成本覆盖：销售价格及折扣、采购、包装/配件、质检/人工、国内运费、头程/关税、提货、入仓/尾程、仓储、平台佣金、广告、退货损失、适用税费与固定开支分摊。按当前工具支持的字段映射；工具没有某项时标“模型未覆盖”，不要塞入不相关字段或声称已扣除。

区分已确认输入、明确使用的工具默认值、缺失值与不适用：
- 未知不填0；工具提供默认值并使用时逐项披露。
- 缺少重大成本时可保留工具计算结果，但必须标“不完整模型结果”，不得称净利润或作盈利推荐。
- 工具不可用时保留市场/货源工作表；不手写替代模型。
- 记录利润率分母、ROI分母与单位；不同定义不混排比较。

价格带情景：在同用途、同规格/数量竞争池的P25/中位/P75有效售价下，对同一个已匹配货源调用当前工具。记录样本量；不可比或太少则不做。只改变明确的售价输入，其他成本参数保持一致并披露。不得暗示提价后销量不变。

保存返回的所有经营情景、明细和建议价；工具未返回的情景/保本价写“未提供”，不得伪造为MCP返回。若需保本价且工具未提供，可在工具调用预算允许时重复调用同一工具做有界求解；记录区间、精度和调用次数，不另建公式。工具返回achievable=false或相同语义时保留失败原因。

结果始终称“1～2款样本的利润/价格情景”，不推断类目真实平均利润率。

## 3. 七张工作表

1. **类目总览**：种子映射、类目ID/中韩名称、数据覆盖、销量/PV、动态价格带、集中度、形态数量、配送表；每类目单独分区。
2. **高销量商品**：类目、排名、嵌入图片、产品ID、中韩名称、规格/件数、售价KRW、近28天销量/PV、销量/PV、评分、评论数、配送、快照日期、商品链接。
3. **潜力商品**：保留以上字段；加真实上架日、首次发现日、日期证据、分组、可比趋势、评论正文覆盖、入选理由、证据缺失。
4. **1688货源匹配**：两端图片并排、ID/链接、对应规格、采购单位、套装换算、阶梯价格CNY、MOQ、供应商、匹配级别、一致/差异项、证据等级、采集时间。
5. **利润测算**：每个“产品×SKU×情景”一行；完整售价、成本、汇率、费率、各费用金额、利润、利润率、ROI、建议价格、计算状态；下方或右侧附工具全部字段明细。原始嵌套结果转为产品/情景/字段路径/值/单位，长内容分行不截断。
6. **完整商品明细**：全部可访问去重商品，不仅推荐款；类目池/直接竞品标识、种子关联、图片、价格/销量/PV/评论/日期/配送及来源证据、入选或淘汰原因。多类目归属可多行，但明确统计键和全局去重数。
7. **参数与数据说明**：输入ID、时间口径、完整性、阈值、翻译/归类说明、全部算价配置和公式说明、默认值使用清单、查询/计算错误、未覆盖成本、来源与图片失败清单。

用户指定不同字段时遵循本次要求；不把无关历史预算硬塞进参数表。

## 4. 图片和可读性

- 图片嵌入工作簿的图片对象，锚定对应单元格、随单元格移动并保留原图比例；另留原图URL。常规商品缩略图建议约90×90px，匹配表两图各约120px，调整行高/列宽，不能用文字“查看图片”充数。
- 遵守当前工具对远程图片的访问和下载限制。能授权获取时使用超时、有限重试、类型/大小检查与去重缓存；不能取图时留“图片未能嵌入”及可点击原URL，统计成功/失败。不能用生成图片补充商品实拍。
- 中文表头、冻结首行和关键商品列、开启筛选、数字右对齐；文本适度换行。币种明确，金额2位小数、比例显示1～2位百分数，不显示浮点尾数。
- 数据区不合并单元格；说明区可合并。链接可点击，长韩文标题不无限拉宽表格。
- 工具结果为已核验数值；公式说明为文字。只有工具公式明确且Excel可忠实复现时才添加可编辑公式列，标版本并用同输入与工具结果对账。不能把没有公式的结果列称作改参数会自动重算。
- 标题/评论等外部文本按文本保存，防止以 =、+、-、@ 开头被误执行为公式；有意添加的计算公式单独处理。

## 5. 交付核验

保存后用XLSX库重新打开，检查：
- 七张表存在，ID按文本保真；商品去重、类目/配送分母、候选回溯能对账。
- 货源和算价均关联到正确Coupang销售SKU；无价格/币种/数量错配。
- 图片对象实际存在且位置正确；检查XLSX媒体与绘图关系，并渲染代表页核验，无法渲染时明确未做视觉核验。
- 数字与原始结果一致；没有#REF!/#DIV/0!等错误，未知费用不伪装为零；金额/比例格式清晰。
- 嵌入图片成功数、失败数和原因可追溯；空结果表仍有字段和原因，无虚构填充行。
- 报告不含凭据、Cookie、私有连接串。

最终只需给Excel下载链接、类目/商品/货源/算价数量、关键发现与未完成项。真实ID或认证缺失时不声称全流程完成。
