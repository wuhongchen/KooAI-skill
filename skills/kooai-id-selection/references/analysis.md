# 类目与潜力商品分析规则

## 1. 种子、类目与覆盖

每次保留种子 ID、标题、链接、图片、类目 ID、中韩文类目名称与完整路径。中译名称属于翻译，不替换原字段。

商品有多个归属时优先核验最新类目商品卡/类目索引与官方路径；不能仅凭关键词确定唯一类目。多个合理归属造成明显不同竞争范围时询问用户；无法定位的ID单列失败，其他ID继续。

建立两个可对账的池：

- 类目池：叶子类目全部可访问、去重后的产品。支持分页时拉完；受配额/分页上限限制则明确终止原因、已取数量及剩余未知。
- 直接竞品池：在类目池中按种子用途、形态及核心规格筛选。型号、大小、颜色、套装等以属性保留。商品数按 product_id 去重，款式类型按本轮解释清楚的规则归类；不是SKU总数。

记录“来源声明总数（可用时）/本次查询数/唯一商品数/指标匹配数/近期指标数”。类目榜单仅有120款就写“榜单样本120款”，不写全市场120款。多个类目汇总再次按product_id去重，类目内统计可重复归属但需说明不可直接相加。

## 2. 时间口径

默认使用项目T-1日期助手或数据服务返回的cutoff。快照不晚于截止日，默认回看60天；主分析使用距截止日不超过14天的快照，其余保留为旧数据组。缺失销量/PV留空，不视作零。

每个商品保留快照日期，汇总注明日期范围及不同快照滚动窗口不完全一致。不把近28天称作自然月；销量/PV只作为比值，不称官方转化率或购买人数。

上架证据分三种：

1. 真实上架日期：来源有明确字段及语义，保存字段与证据；默认90天内可进入真实新品池。
2. 首次发现日期：来自完整可访问历史中的最早记录，仅表示系统首次看到；回看60天的最早记录不是全历史首见。
3. 日期未知：首条评论日、创建缓存日、同步日、created_at等未经验证不能替代上架日。

没有真实上架日的商品另列“近期首次发现候选”；两种日期都未知但有动销的商品可列“普通潜力观察”，不标新品。没有覆盖完整历史时标明首见日期的查询边界。

## 3. 高销量与潜力组

类目总览及直接竞品概况分别输出：商品数、有效销量/PV覆盖、有动销数、近28天销量/PV合计、销量/PV比、中位价、中位评论数、Top1/5/10销量集中度、主要形态、动态价格带。Top20按同口径销量排序；旧快照不挤入近期榜，覆盖不足写“已覆盖近期样本Top”。

潜力候选起始筛法：真实上架不超过90天、近28天销量10～300、评论3～100、评分至少4.3、PV至少500，排除近期有效商品销量分布的头部10%。当来源不是5分制时先核验并调整，不机械使用4.3。

这些是可调整的起始阈值，不是永不变的硬条件。先看分布，再明确本轮阈值、调整原因和排除数量；并列边界统一处理，极小类目不强行切十分位。高销量不等于机会，低销量也可能是无需求；更关注已有成交、访问持续、评价门槛较低、产品可差异化。

查询候选可用的评论正文，记录条数、时间、评分分布与抽样偏差；检查尺寸、材质、破损、异味、色差等实际问题。评论少于10条标“好评证据弱”；只有总评分则写“评分较高，正文未核验”，不写无差评。

趋势使用同一商品历史快照，记录两端日期及可比性；滚动28天差值不是新增订单数。新品曝光时间短，不能把低累计销量直接判成劣势。保留推荐、观察、排除及原因，不要求每类都产候选。

## 4. 配送匹配与分母

选择类目最近完整批次，记录周、采集时间和完成状态。数据库适配器应核验表结构、batch/subtask/category等完整关联键，不能仅按可能复用的任务ID连接；避免重复批次放大样本。

以该批次内唯一产品ID建立固定配送分母。互斥分类为：明确无火箭、橙色商家火箭、蓝色火箭、紫色跨境火箭、灰色安装火箭、其他已知火箭、未知。分类须依据当前已核验的徽标/字段映射；来源标志冲突且无法按具体销售SKU消解时归入未知并记录冲突，不能靠颜色优先级强行归类。普通物流DOMESTIC不构成颜色证据。

表格同时给商品数/商品占比、近期指标覆盖数、已覆盖销量/销量占比、PV：
- 商品占比＝本类商品数/配送固定商品池数。
- 销量占比＝本类有效近期销量/同一配送商品池有效近期总销量。
- 分母为零或未知时写“不可计算”，不是0%。
- 无卡片对应的扩展商品不猜颜色；单列为扩展池配送未知，不污染完整批次占比。

颜色互斥数之和须等于配送池数；火箭合计是派生指标，不重复加入分母。多来源、跨批次或跨日期时保留每商品证据。没有完整批次就只展示可核验样本，不发布“全类目占比”。

## 5. 选1～2款

默认整个任务1～2款，不随输入ID数量倍增；多类目时解释取舍。优先选择潜力池中需求证据较明确、评价门槛低、规格可匹配且尚未明显被头部品牌锁定的款式，尽量不同形态。

缺少卖家画像时明确“仅作市场机会初筛”，不假定新卖家/预算/履约方式。若没有证据足够的潜力款，允许以头部商品做成本对标，但标“成本参照，非推荐进入”；不能强行凑推荐。
