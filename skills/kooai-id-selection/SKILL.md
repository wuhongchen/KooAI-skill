# 商品ID横向选品

输入商品 ID，回答“这个类目卖什么、哪些新进入者已有动销、配送门槛如何、可验证哪1～2款”。固定交付一份带嵌入图片的 XLSX；不默认生成 HTML，不修改后台或管理库存。

## 输入与启动

- 接受一个或多个 Coupang product_id 或商品链接；itemId、vendorItemId 单独保存，不当作 product_id。
- 未提供 ID 时仅请求 ID，不代选无关品类。多个 ID 同类目合并、跨类目分开；默认整个任务选1～2款找货。
- 默认 T-1 截止、近28天销量/PV，记录实际数据日期；不继承其他任务的进价上限、利润目标或品类排除条件。
- 默认使用已认证 KooAI MCP；本次环境提供且允许使用项目数据适配器时可只读查询数据库。先发现当前工具/schema并执行真实查询，不能用健康检查代替数据验证。
- 如数据认证失败，停止依赖查询，不生成伪报告；局部缺失保留已有事实和未完成项。

## 执行

1. **类目定位与全量范围：**读取 [分析规则](references/analysis.md)。核实种子商品所属叶子类目，建立“类目完整已覆盖商品池”和“同用途/形态直接竞品池”，分页穷尽可访问数据。记录重复、缺失及覆盖范围。
2. **两组结果：**按销量列出类目 Top20 参照；筛出近期入场、低销量已有好评的潜力商品。阈值随类目分布调整，公开阈值及理由。真实上架日与首次发现日分列；样本少不强行凑数。
3. **配送结构：**从同类目完整采集批次的商品卡匹配配送；橙、蓝、无火箭为重点，同时保留紫、灰、其他、未知。商品与销量分母分开，不从 DOMESTIC 推断颜色。
4. **找货：**从潜力组优先挑1～2款，选择依据写入表格。使用已安装的 kooai-1688-sourcing 与 1688-product-find，先阅读对应技能及命令 reference。图片相似不等于规格匹配；标明用途、材质、尺寸、数量、包装、MOQ与SKU的一致和差异。
5. **统一算价：**读取 [价格与Excel规范](references/excel-pricing.md)，发现并调用 get_pricing_config、calculate_product_pricing 的当前 schema。仅对证据足够的SKU算价，保留全部输入、默认值、工具返回结果和缺失成本。
6. **Excel交付：**使用环境中可用的 spreadsheets:Spreadsheets 技能；没有该技能时用现有 XLSX 库实现同一规范并验证。嵌入图片、链接、商品数据与全部算价明细；不以 CSV、纯文本或图片URL代替已承诺的Excel。

可复用 category-data-explorer 的查询能力，但本技能的 ID 输入、双商品池、近期候选和七张工作表契约优先。依赖不可用时只暂停受影响步骤，不自行安装或配置凭据。

## 决策与交付边界

- 七关漏斗（卖家适配、需求、趋势、竞争、差异化、单位经济、合规履约）作为内部完整性核验；Excel只呈现简洁中文结论、证据与风险，不展开七关状态矩阵。
- 机会分非必填。有分数时披露权重、缺失项及版本；缺证据不补零、不转成正向推荐。
- 仅1～2款成本核验不能代表类目真实利润率。输出“已核验款的预估/确认利润”和“类目价格带情景”；不同售价不保证相同销量。
- 未找到匹配货源、工具不可用或成本缺失时，未核验字段留空并写明原因。询价、供应商承诺、销量、上架时间、火箭颜色、图片、费用均不得编造。
- 出现登录、验证码或访问限制时，按所选工具规则停止并请求人工介入；不下单、不付款、不发布商品、不上传报告。
- 完成前按Excel规范对账并重开工作簿验证；报告实跑了哪些环节，不将文档校验称为线上端到端通过。

## 调用示例

```text
$kooai-id-selection
商品ID：<填写一个或多个真实Coupang商品ID>
横向分析所属类目，查看高销量参照与近期低评价动销商品；
拆分火箭配送，选1～2款匹配1688，使用当前KooAI算价工具；
导出带图片、完整价格及计算明细的Excel。
```
