# 场景分析与理由证据契约

## 场景不是类目名称

一个场景是一条任务链：**有某种需求的人，在特定时刻/地点，因为一个触发，要完成一个动作，但现有方案存在某种取舍，于是考虑某类商品。**

每个细分场景记录以下字段，不必人为凑齐相同数量的产品：

| 字段 | 要回答的问题 | 证据边界 |
|---|---|---|
| 需求人群 | 谁实际面对这项任务？ | 用行为定义，如携带固体皂的人；无画像数据不猜年龄、性别或人群规模 |
| 时刻与触发 | 什么时候、什么事件使需求出现？ | 例如洗完后收进包；把发生频率与购买频率分开 |
| 核心动作 | 买家真正想完成什么？ | 写“隔离湿皂与其他物品”，不是泛泛的“提高生活品质” |
| 现用方案 | 不买也能怎么解决？ | 列替代方案及利弊；未有评论时标为功能分析假设 |
| 购买动机 | 为什么替代方案不够？ | 便利、兼容、耐用、卫生、整洁等必须落到具体属性，不编造情绪或韩国用户偏好 |
| 必要特征 | 哪些规格才算解决这个任务？ | 尺寸、开合、材质、套装、安装、清洗；商品标题声明不等于效果验证 |
| 需求机制 | 常用、磨损替换、一次性消耗、补充装中的哪种？ | 无订单证据不报复购率/周期；一次性物品与可重复清洗替代品分别比较 |
| 本地适配 | 韩国的什么条件影响使用？ | 有来源才称事实；接口尺寸、用语等未核验标待核，不套“韩国人都喜欢” |
| 关键词 | 中韩用途词、形态词、排除词是什么？ | 搜索词只提供入口，不是热度证据 |

从一级空间列不同动作，再聚合到产品形态。帽型保护与内衣防缠绕虽然同属洗衣，不是同一任务；同一款收纳袋进入办公、旅行两个场景不代表两份独立销量。缺少场景级标签或评论时，表述为“场景假设；该商品总体销量支持需求存在，不能归因到该场景”。

## 入选理由的四段结构

1. **为什么买（推断/评论证据）**：具体任务、替代方案、购买触发、与商品特征的关系。若引用评论，附产品ID、评论日期和样本数；没正文就明确为功能推断。
2. **为什么看这款（事实＋限定推断）**：引用商品指标、日期以及同用途可比组的规模/排名、评价或价格对照。可比组不足时退回类目背景，并明确“尚不能证明细分竞争空缺”。低评价只能说明评价积累较少，不等于新上架或低竞争。
3. **为什么未必适合（反证）**：至少指出本商品最相关的风险或替代解释，如低价竞争、同类橙火占比高、促销窗口、头部集中、规格价冲突、功能替代品已足够、样本陈旧或尺寸兼容不明。不是给所有商品粘贴相同风险列表。
4. **判定边界（待验证）**：写哪项可观察证据会使判断升级或降级。例如同用途低评价商品几乎无成交、真实规格价落在低价带、尺寸不兼容时应降级。不列下单、采购、投放操作。

理由必须解释对照结果的商业含义，不只是复述数字。若“评价较少”的对照实际更高，改为需求参照；若商品身份、数据日期或价格口径相互冲突，先降为待核验。没有完整成本时不使用“高利润、可盈利、低风险拿样”等结论。

### 示例（逻辑示例，不含市场事实）

**便携沥水皂盒**：有携带湿皂需求的人，清洗后要收进随身包；普通袋子可隔开物品，但是否便于沥水、重复清洁存在取舍（功能假设）。只有标题确有便携/沥水结构的商品才进入可比组。该组存在多个有销量且评价积累较少的商品，才支持研究细分需求；整个皂托类目销售较高不足以证明便携款机会。如果实际用户更重视防漏而产品只有敞口沥水功能，原场景匹配应降级。评论不足时不宣称“防漏是韩国买家第一痛点”。

## 研究顺序与结论

先处理身份/数据冲突，再比较场景任务清晰度、需求证据、非头部承接、评价与配送障碍、差异可验证性。给自然语言的优先顺序，不把异质维度随意加总为百分制。

- **优先研究**：具体任务清晰且有对应商品证据，关键对照与反证可解释；仅为市场研究顺序。
- **观察**：任务合理但进入空间薄弱，或只有有限样本支持。
- **需求参照**：用于证明形态能动销、理解主流规格；不作为低评价切入口。
- **证据不足**：身份/日期/价格冲突或关键指标不足，不能支撑比较。
- **排除**：命中本轮硬性条件，保留原因。

合规另列“确认适用／确认不适用／待核验”及来源，市场优先不覆盖合规门槛。排除 KC 的任务中，未知商品只能进待核验研究表，不进入合格推荐表。缺市场数据只交付待检验场景假设，不将其包装为已证实机会。

## 可比商品池

- 每个类目采用截止日前最新完整采集批次，以产品 ID 去重。关键词扩展池和类目固定池分别汇总，记录已检索页数、总量是否可知和未覆盖范围。
- 保留全部商品；用途不符者标排除，核心范围统计要同时调整分子、分母。父子类目合计和跨场景总览按 ID 去重。
- 商品历史默认回看60天寻找截止日前最近快照；当前销量有效期默认14天，用户指定优先。明确实际指标日期范围。旧快照可展示为历史参考，但不参与当前动销。
- N=全部唯一商品；V=日期有效且销量为非负有限数的商品；M=V中销量>0；Z=V中销量=0；U=N−V。展示 M/V、V/N、M/N，满足 N=V+U、V=M+Z。零分母留空，缺失不是零。
- 汇总称「已覆盖近期快照的近28天销量」，不称全市场或统一自然月。PV 独立校验并记录覆盖；销量/PV仅用二者共同有效样本，不称平台官方转化率。产品销量不等于所展示某个变体销量。
- 火箭取同批类目卡片布尔/徽标证据：明确无火箭、橙、蓝、紫、其他、未知互斥。项目现有字段依次为 has_rocket_delivery=false、is_rocket_merchant、is_rocket、is_coupang_global、其余明确火箭、未知；保留冲突标志。DOMESTIC不代表任意颜色。数量占比与已覆盖销量占比分列、分母明确。
- 价格需对应规格、数量与采集时间；历史价格和卡片价冲突时并列，未核对不能用产品销量乘变体价称真实销售额。
- Top1/5/10、低评价门槛和价格带基于同一有效池；卖家集中度需要卖家 ID，不能用商品集中度替代。广告竞争未知时不能从自然排名推断。

## 来源与风险

市场数据保留原字段与来源标识；韩文名与中文译名分开。合规按具体用途、材质、年龄、接触食品/人体、声明、进口主体与履约路径查韩国官方现行资料；没有 KC 字段不是豁免。不得将符合其他标准、供应商口头声明或竞品在售当作韩国合规证明。

本轮采集权限只用于任务内读取；密钥使用安全配置，不写入 Skill、报告或分享文件。不要安装未获授权的付费服务或绕过验证码。

## 交付核验

每个研究候选能回到完整商品记录；场景引用的商品ID存在且数据日期一致。场景归因、功能效果、复购与本地偏好明确区分事实和假设。入选理由有本商品特定的支持、对照、反证与判定边界。表格、页面和CSV使用同一场景映射；相同产品跨场景不重复累计销量。主表没有货源、采购报价和利润栏目，也不因未连接采购服务而显示失败。
