# KooAI 场景日用与消耗品选品

从「具体使用情境 → 待完成任务 → 购买动机 → Coupang 市场证据 → 进入空间」寻找日用品与耗材机会。重点回答为什么有人需要、为什么选择这种产品、为什么值得继续研究。日常使用不等于高频购买，消耗品也不天然低竞争。

本 Skill 只做市场侧分析：类目、商品、评论、趋势、配送与场景判断。不执行 1688 搜索、货源匹配、采购成本或利润测算；完整报告也不触发这些流程，不保留待找货、待算价的空列。用户另行提出采购核价时，作为独立任务处理，不改变本 Skill 的默认边界。

## 本轮范围

从当前请求和已确认上下文整理：场景、卖家阶段、排除项、时间窗口、数据入口、查询范围、交付形式。已有答案不重复问；只询问会实质改变任务的缺项。

- 市场默认韩国 Coupang，截止日默认 T-1；使用可用项目日期工具，不把最后一次入库日期伪装成 T-1。
- 未指定场景：先覆盖厨房、卫浴、清洁洗衣、收纳、办公、宠物日常护理，说明这只是本轮探索范围，不是全站扫描。
- 有当前卖家条件就沿用；无上下文时用「新卖家小批验证」作为明确假设。没有固定进货价、净利润、日单量或候选数门槛。
- 用户要求低合规负担/排除 KC 时，分别列需要 KC、确认不适用 KC、待核验；后两者不能混同。食品接触、卫生用品、化妆品等其他监管另查。未知者留在待核验表，不挤掉已经查到的市场事实。
- 食品、儿童、电器、电池、季节性、大件等排除项按本轮配置，不能把本次厨房案例固化为所有用户的永久条件。

## 执行

执行市场分析前读 [references/method.md](references/method.md)。

1. **场景拆解**：厨房、卫浴等只作为一级入口。每个候选方向填写「有何需求的人、具体时刻/地点、触发事件、要完成的动作、现有替代方案及取舍、购买触发、产品必要特征」。只有任务、约束或购买决策发生变化才另拆场景，不把颜色或同义词变成多个机会。人群画像和未采集到的痛点标为推断。
2. **身份清洗**：从类目树定位实际范围，检查商品标题/规格。排除同词异物和用途污染；如一次性丁腈手套不等于隔热手套，食品用不等于医疗用。场景可跨多个类目，全局按产品 ID 去重。
3. **查市场**：用已认证 KooAI MCP，或用户指定且可用的只读 RDS；先确认真实查询成功和实际字段。服务不可用就交付研究框架/已完成部分，不生成市场数字。有 `category-data-explorer` 时用于类目统计；没有时按本 Skill 的数据契约执行。
4. **查动销和空间**：同时看覆盖率、动销率、销量/PV、Top1/5/10 份额、评价壁垒、配送分布、价格带。先核对用途、规格和包装形成可比组，再比较销量排名、评价分位与售价；宽类目只提供背景。头部参照、研究候选、观察与排除分别呈现，不能把头部或高评价参照混进“低评价机会”。阈值与统计分母按本轮分布披露。
5. **查复购逻辑**：记录消耗机制、替换原因、每次用量、包装数量、存储体积和季节性。没有订单复购或可靠使用证据时，复购周期是待验证假设，不报实际复购率。大包装低客单要检查单件/每100只/每米等单位价格和体积运费。
6. **查买家痛点**：有评论正文时按产品和日期去重，区分尺寸、耐用度、破损、异味、包装、使用便利等；记录正文样本量与覆盖。没有正文时列缺失，不编造痛点或“无差评”。
7. **解释原因**：按 method.md 的四段证据链逐商品填写「为什么买、为什么看这款、为什么未必适合、还缺哪项证据」。至少一项可回查的商品事实、一项有分母的对照、一项反证或替代解释。销量/评价只支持现象，不自动证明场景归因、用户偏好或产品效果。
8. **给出研究优先级**：使用「优先研究、观察、需求参照、证据不足、排除」。先看身份与数据可信度，再看具体任务是否成立、非头部商品能否承接需求、评价与配送障碍以及可验证的差异。说明高于其他候选的原因；不额外拼凑无校准总分。市场研究优先级与合规状态分列，KC 未知不能转成采购或上架推荐。

## 交付

普通问答给场景/类目对比表和候选表。用户要求完整报告时，生成可筛选的本地 HTML 与 XLSX；仅指定一种形式则只做该形式。创建 XLSX 时使用可用的电子表格 Skill。

- **场景机会**：具体情境、需求人群、触发与动作、替代方案、购买理由、产品必要特征、用品类型及替换机制、中韩关键词、支持事实、反证、研究顺序及依据。
- **类目分析**：N/V/M/Z/U、三项动销比例、覆盖销量/PV、Top1/5/10、价格带、火箭分布及日期。类目统计不能充当某个细分场景的销量。
- **商品与理由**：名称、图片、规格、售价、销量/PV、评价、配送、研究角色、四段理由、合规状态、指标日期和 Coupang 链接。具体解释不足的商品保留为观察，不套用通用推荐文案。
- **完整商品及排除记录**：保留不合格、用途冲突、指标缺失、过期商品和原因；不因未入选而丢行。
- **数据说明**：实际范围、日期、覆盖、可比组与阈值、事实/推断、合规证据。复用旧数据时明确说明仅重做分析，不称为重新采集。

表格以具体场景、名称、图片、价格、销量和简短入围理由在前，ID/审计字段靠后；完整证据链点击展开。理由写成中文，不用英文状态与七关矩阵占满主表，不展示操作型“下一步”列。图片完整显示并可查看大图；保留币种和计算口径。HTML 筛选后的可见行支持 CSV 导出，导出包含场景与理由，行数与页面一致。所有生成文件放独立输出目录，不修改业务前端。

## 调用示例

> 使用 $kooai-scenario-selection，分析韩国厨房和卫浴的日用品与耗材。排除儿童、电器、大件、季节性及需要 KC 的产品，合规不明单列。拆解真实使用情境、替代方案与购买动机，用 Coupang 类目、商品和评论数据说明哪些方向值得研究、为什么以及什么证据会推翻判断，输出含图片的 Excel 和可筛选页面。

只读分析不自动写飞书、下单、联系供应商、发布、推送 GitHub或创建定时任务。用户另行要求这些动作时按对应授权执行。
