# KooAI 爆品跟随与附属需求探测

寻找「韩国热点主品 → 使用人群/任务 → 配件、替换件、耗材、互补商品 → 独立销量证据」。主品火爆不等于附属品赚钱；“跟随”是需求关联，不是复制品牌、图案或专利。此 Skill 是按次执行的探测工作流，不自带常驻监控服务。

## 输入与范围

接受主品名称、Coupang ID、新闻/视频/帖子链接或开放式找热点。整理本轮韩国市场、内容观察期、商品截止日、卖家条件、排除项、是否货源算价、预算与输出方式。默认内容观察近30天、市场截止T-1；旧事件可作背景但不算新热点。

没有指定主品时，先发现并去重一组热点种子，再按可验证性分批深入，说明检索渠道与停止边界。不设必须找到几个爆品的配额；证据不足允许没有合格机会。已确认条件直接沿用；不把旧任务的进货价或销量目标作为通用默认。

执行前读 [references/evidence.md](references/evidence.md)。

## 执行流程

1. **查韩国信号**：实时检索韩国媒体、品牌/零售商官方发布、公开社区、Naver Blog/Cafe、YouTube 等实际可访问来源。打开原文核对发布日、事件日、韩国关联、产品身份和热度依据；访问不到就记录，不凭标题补正文。转载和同稿只计一个来源。品牌营销/软文单列，不当独立销量证据。
2. **主品验证**：把“热议”“缺货声称”“销售增长”“累计销量”分别记录。新闻称爆款但市场查询没证据时只标「内容信号待验证」；Coupang单个平台缺失也不等于韩国市场没有需求。能匹配主品时保留产品/类目 ID、指标、日期与实际覆盖。
3. **构造附属需求**：对每个主品生成「保护收纳、清洁保养、补充耗材、磨损替换、兼容适配、使用便利」中确实相关的方向；无关类型不用凑满。写清使用依赖、韩文词、购买触发、是否复购、型号适配、季节性与侵权风险。关联是推断，不是销量事实。
4. **独立查附属品**：逐方向查类目、产品、历史、评论；有条件调用 `category-data-explorer`，否则执行 evidence.md 契约。每个方向列已覆盖总量、动销、集中度、火箭分布、价格带与中腰部商品。主品销量、评论、价格不能移填附属品。
5. **验证传导**：新闻/主品上升之前和之后是否有可比的附属品数据？按固定商品池、相同口径、真实日期对比；同时看未受热点影响的对照方向（可用时）。优先用不重叠窗口；重叠的滚动28天窗口只说明指标变化，不能称新增订单或因果提升。关联发生在事件之前、供给扩容、广告促销、季节性等其他解释要写明。
6. **筛入场空间**：把主品热度、附属需求合理性、附属品实际动销、竞争/交付、供应链/利润分别判断。成熟头部作参照，中腰部有销量/PV且评价相对少才进入验证池。没有真实上架日期不叫新品；缺卖家数据不说卖家垄断或竞争小。
7. **货源与算价**：完整机会报告或用户明确要求时，优先选择证据最强、风险较低的代表款；用可用1688找货能力或指定Ego核验同规格，再用当前KooAI统一算价。方法见 evidence.md；无成本就不写利润数字。单纯分析新闻不自动扩大为采购核价。
8. **分级**：分别展示「热点已核实/仅内容声量/待验证」「附属品已有动销/仅关联假设」「值得验证/优先拿样/观察/排除」，附中文依据与缺失证据。没有时间序列不宣称“由爆品带动”，没有样品和经营验证不称确定可卖。

## 交付形式

先回答：哪些热点有可信依据、哪些附属品本身卖得动、哪些只是想象。一般问答给紧凑表格；完整报告默认本地 HTML + XLSX，用户指定格式则遵从。生成 XLSX 使用可用电子表格 Skill，结果留在独立输出目录，不修改业务前端。

| 表 | 必需内容 |
|---|---|
| 热点主品 | 主品/品牌/型号、韩国渠道、原文链接、发布/事件/观察时间、声称热度、核验事实、营销标识、主品数据及覆盖 |
| 附属机会 | 主品→附属品关系、用途、中韩关键词、类目、适配要求、复购假设、时间传导证据、动销与覆盖、配送份额、竞争与风险、状态和理由 |
| 商品明细 | 图片、中韩名、主品归属、附属品 ID、规格、售价、销量/PV、评分/评论、火箭、指标日期、Coupang链接、入围状态 |
| 货源与利润 | 1688图片/标题/链接/SKU、报价单位/MOQ、匹配差异、证据等级、成品成本、模型输入/默认值、利润金额/利润率/ROI、保本/目标价、公式说明与时间 |
| 排除与说明 | 错配、仅热点无动销、强品牌/适配/侵权/合规风险、未知/过期、阻断和缺口；统计分母与证据来源 |

主表用横向完整列展示，图片完整可放大，金额与百分比两位小数、注明币种；算价明细/公式与长证据点击展开。HTML 支持筛选并导出当前可见行 CSV；推荐、观察与淘汰都能查看，不用技术警告淹没结果。

## 调用示例

> 使用 $kooai-hit-following 查最近30天韩国新闻和公开内容中的爆品，不直接卖主品，找它带来的耗材、收纳和替换件机会。核验Coupang动销与橙/蓝/无火箭占比，主品涉及电器不影响研究非带电配件，但候选排除儿童、季节性、大件及需要KC的商品。对优先方向核验1688与统一算价，输出含图片Excel。

热点不会自动取得商品图片/商标授权。需要型号专用适配或认证的候选单列核验，不以“副厂通用”跳过。除非用户明确要求定期监测，否则仅执行本轮；定期请求用宿主调度能力，写入/发布/推送须在相应授权范围内。
